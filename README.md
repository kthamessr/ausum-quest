# AUSUM Quest

A web-based cognitive adventure game designed to promote thinking, communication, logic, and engagement for autistic adolescents.

## Current Features
- World map
- Mission system
- XP and ranks
- Reward system
- Unlockable worlds
- Animated UI
- Autism-friendly design

## Tech Stack
- React
- Vite
- Framer Motion
- Tailwind CSS

## Future Goals
- Speech recognition
- Companion creatures
- Adaptive difficulty
- Save system
- Parent dashboard
